# 편의성 모음 (ST Quick Actions)

SillyTavern 편의 확장입니다. 다른 확장 없이 혼자 동작합니다.

## 설치

SillyTavern → 확장(Extensions) → **Install extension** → 아래 주소를 넣고 설치한 뒤 새로고침합니다.

```
https://github.com/zxvniqi/ST-QuickActions
```

## 사용

입력창 왼쪽 **마법봉 → 편의성 모음**에서 기능마다 켜고 끕니다.

- 기능은 분류별 탭으로 나뉩니다. 맨 위 **기능 찾기**로 검색하고, ☆ 를 누른 기능은 **즐겨찾기** 탭에 모입니다.
- 기능 이름 아래 한 줄 설명을 누르면 자세한 도움말과 쓰는 곳이 펼쳐집니다.
- 비슷한 기능은 한 줄에 칩으로 모여 있고, 칩마다 따로 켜고 끕니다.
- 🎨 로 설정창 색을 고릅니다(숲·바다·장미·라벤더·밤·테마 색).
- 창 맨 위의 **사용**을 끄면 확장 전체가 꺼집니다.

## 기능

- **메시지**: 삭제 버튼 꺼내 두기, 메시지 끝으로 가기, 메시지 다시 그리기 버튼, 답변 넘기기 버튼, 메시지 처음으로 가기, 드래그해서 수정·삭제(번역문·원문), 스와이프 목록(번역문 미리보기, 원문 그대로 크게 보기), 빈 답변 자동 삭제·재생성, 정규식 렌더링 픽스
- **채팅**: 메시지 범위 삭제·숨기기, 채팅 단어 한꺼번에 바꾸기(미리보기·일부만·단어 단위·범위·되돌리기), 채팅에서 찾기, 메시지 휴지통(옵션 메뉴에 개수 표시), 채팅 전체 내보내기·불러오기, 채팅 목록 정렬, 채팅 이름을 페르소나·캐릭터 이름으로, 채팅 백업 캐릭터별로 보기·불러오기, 캐릭터 누르면 채팅 목록부터(채팅 하나 불러오기·백업 보기·캐릭터 삭제도), 시작 화면에 최근 채팅 펼치기, 빈 채팅 덮어쓰기 방지
- **캐릭터**: 목록에서 바로 즐겨찾기·태그, 프로필 사진 고화질, 페르소나 메모·연결 캐릭터·폴더(채팅 고정도 연결로, 지금 캐릭터에 연결된 페르소나 보기)
- **입력창·QR**: QR바 정리, QR 입력창 도구, QR 답변도 스와이프로 다시 만들기, 입력창 안내 문구 숨기기
- **바로가기**: 최근 메시지 삭제(스와이프만 / 메시지 전체), 맨 위·아래로, 한 메시지 위·아래로, 번호로 이동, 메시지 범위 숨기기, {{char}}·{{user}} 이름 바꾸기, 마법봉·옵션 메뉴·입력창 버튼·확장 설정 추가(아이콘·처음 탭 고르기), 삭제·숨기기 중 이동 버튼
- **프롬프트**: 프롬프트 폴더·관리(목록 검색), 빠른 전환(항목 켜기·끄기 조합 저장, 채팅에 연결하면 자동 전환), 프롬프트 항목 메뉴(복사·맨 위로·맨 아래로·삭제), 다른 프롬프트에서 가져오기, 다른 프롬프트 항목으로 교체, ☰ 눌러서 옮기기
- **메뉴 정리**: 메뉴 숨기기·순서 바꾸기(≡ 끌거나 눌러서 옮기기, 입력창 버튼·확장 설정은 왼쪽·오른쪽 사이로도), 확장 메뉴·옵션 메뉴를 아이콘으로, 확장 설정 바로가기(옵션 메뉴·마법봉·메시지 메뉴에서 창으로 열기, 아이콘·처음 탭 고르기), 정규식 폴더
- **화면 · 기타**: ST 한국어 번역 채우기·고치기, 프롬프트·월드인포·캐릭터 설명 번역해서 보기(위치별로 켜기, 여러 곳 동시에, 크게 보기), ST 설정 설명 글씨 숨기기, 월드인포 목록 창(찾기·즐겨찾기·정렬·연결 캐릭터), 오류 알림 자세히 보기(그 알림 오류만, 이전 것은 접기), 연결 프로필 버텍스(서비스 계정) 오류 픽스

## 서버 기록 플러그인 (선택)

깔면 "오류 알림 자세히 보기" 창의 **서버 화면**에서 그 오류 무렵 서버 콘솔(터묵스 등)에 찍힌 기록도 함께 봅니다. 안 깔아도 확장은 그대로 씁니다.

1. ST를 끕니다.
2. 확장 폴더의 `server-plugin/stqa-log` 폴더를 ST의 `plugins` 폴더로 복사합니다.
   ```
   cd ~/SillyTavern
   cp -r data/default-user/extensions/ST-QuickActions/server-plugin/stqa-log plugins/
   ```
   (확장을 "모든 사용자용"으로 깔았다면 `public/scripts/extensions/third-party/ST-QuickActions/server-plugin/stqa-log`)
3. `config.yaml`의 `enableServerPlugins`를 `true`로 바꿉니다.
   ```
   sed -i 's/^enableServerPlugins: false/enableServerPlugins: true/' config.yaml
   ```
4. ST를 다시 켭니다. 켤 때 `server plugin(s) are currently loaded` 줄이 나오면 설치된 것입니다.

확장을 업데이트해도 플러그인은 자동으로 바뀌지 않으니, 플러그인이 바뀐 업데이트라면 2번을 다시 해 주세요. 사용자 계정을 켠 ST에서는 관리자 계정만 서버 기록을 봅니다.
