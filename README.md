# 편의성 모음 (ST Quick Actions)

SillyTavern 편의 확장. 다른 확장 없이 단독으로 동작합니다.

**설정은 채팅 입력창 왼쪽 마법봉 메뉴 → 편의성 모음**에서 합니다. 기능 켜고 끄기, 이름 치환 모두 여기 있어요.

## 기능

1. **메시지 삭제 버튼**: 메시지 메뉴의 수정(연필) 버튼 옆에 휴지통 버튼이 생깁니다. 수정 모드에 들어가지 않고 바로 삭제할 수 있습니다.
   - 기본 삭제와 똑같이 동작합니다. "삭제할까요?" 확인창이 뜨고, 스와이프가 여러 개인 마지막 AI 메시지에서는 "스와이프만 삭제 / 메시지 전체 삭제"를 고를 수 있습니다.
   - 확인창 표시 여부는 SillyTavern 설정의 *Confirm message deletion*을 따릅니다.
   - 기존 수정 모드의 삭제 버튼은 그대로 있습니다.
2. **캐릭터 선택 시 채팅 목록**: 캐릭터 목록에서 캐릭터를 누르면 최근 채팅으로 바로 들어가지 않고 채팅 목록 창이 뜹니다.
   - 원하는 채팅을 누르면 그 채팅으로 바로 열립니다. 최근 채팅을 거치지 않습니다.
   - 검색창(메시지 내용 포함), "새 채팅" 버튼이 있습니다.
   - 기본 채팅 관리처럼 채팅마다 **이름 바꾸기 / 내보내기(.jsonl, .txt) / 삭제** 버튼이 있고, 위쪽 **불러오기**로 채팅 파일(.jsonl, .json)을 가져올 수 있습니다.
   - 채팅이 하나도 없는 캐릭터, 이미 선택된 캐릭터(카드 편집 열기), 일괄 편집 모드는 기본 동작을 그대로 따릅니다.
3. **{{char}} / {{user}} 이름 치환**: 칸에 이름을 적으면 모든 채팅에서 `{{char}}`, `{{user}}`가 그 이름으로 바뀝니다. 비우면 원래 이름으로 돌아옵니다. 다인봇에서 QR을 돌릴 때 유용합니다.
   - 체크박스로 켜고 끌 수 있습니다. 끄면 적어둔 이름은 그대로 남고 치환만 멈춥니다.
   - 기존 매크로 엔진, 실험적 매크로 엔진 둘 다 지원합니다.
   - QR에서 바꾸고 싶으면 `/qa-char 이름`, `/qa-user 이름`도 쓸 수 있습니다. (이름 없이 쓰면 원래대로)
4. **글자 드래그로 바로 수정/삭제**: 메시지에서 글자를 드래그(폰은 길게 눌러 선택)하면 **수정 / 삭제** 버튼이 뜹니다.
   - 버튼 위치는 편의성 모음 창에서 고를 수 있어요: 화면 아래(입력창 바로 위, 기본) / 선택한 글자 위 / 선택한 글자 아래.
   - 그 자리에 다른 확장의 떠 있는 버튼이 있으면 알아서 피해서 뜹니다. (아래 설정이면 더 아래로, 나머지는 위로) (폰 자체의 복사·붙여넣기 메뉴는 웹페이지에서 위치를 알 수 없어서, 겹치면 위치 설정을 바꿔주세요)
   - **수정**: 팝업에 선택한 부분이 뜨고, 고친 내용이 메시지 원문에 그대로 적용됩니다.
   - **삭제**: 선택한 부분만 원문에서 지웁니다. 바로 뜨는 알림을 누르면 되돌릴 수 있어요.
     - 번역된 메시지는 삭제 전에 **번역문과 원문을 나란히 보여주는 확인창**이 떠요. 어느 쪽에서 지울지 체크로 고를 수 있어요. (원문 위치를 정확히 못 찾았으면 원문 삭제는 꺼진 채로 떠요)
     - 지워질 부분은 앞뒤 문맥 속에 **형광펜**으로 표시돼요. 다르면 칸 안에서 길게 눌러 직접 다시 고르거나, **시작 ◀ ▶ / 끝 ◀ ▶** 버튼으로 한 단어씩 늘리고 줄일 수 있어요.
   - `**굵게**`, `*기울임*`, HTML 태그가 섞인 부분도 원문 위치를 찾아서 처리합니다. 정규식 등으로 화면에 보이는 글이 원문과 많이 다르면 못 찾을 수 있는데, 그때는 알림이 뜹니다.
   - 번역 확장으로 번역된 메시지는 화면에 보이는 번역문이 고쳐집니다. 수정 창의 **원문 전환** 버튼을 누르면 선택한 부분에 해당하는 원문으로 바뀌어서 원문도 고칠 수 있어요. (문단·대사·문장·쉼표 구절 순서로 맞춰 찾고, 일본어처럼 어순이 비슷한 원문은 선택한 만큼만 잘라서 찾아요. 영어처럼 어순이 다른 원문은 해당 구절·문장 단위로 찾아요) 다시 누르면 **번역 전환**. 둘 다 고치면 둘 다 적용돼요.
   - 원문을 고칠 때 **번역 그대로 두기**를 켜두면 다른 확장에 "원문이 바뀌었다"고 알리지 않아서, 대부분의 번역 확장이 다시 번역하지 않아요. (번역 확장에 따라 다를 수 있어요)
5. **메뉴 정리 (숨기기·순서 바꾸기)**: 편의성 모음 창의 **메뉴 정리**에서 아래 세 곳의 항목을 숨기거나 순서를 바꿀 수 있습니다.
   - **마법봉 메뉴**, **입력창 버튼**(왼쪽/오른쪽), **확장 패널**(왼쪽 열/오른쪽 열)
   - 탭으로 영역을 고르고, ≡ 를 끌어서 순서를 바꾸고, 눈 아이콘으로 숨기거나 보이게 합니다. 각 항목에 원래 아이콘이 같이 보여요.
   - **저장**을 눌러야 적용되고, 취소하면 아무것도 안 바뀝니다. 나중에 추가된 확장의 항목도 자동으로 반영됩니다.
   - 숨기면 쓸 수 없게 되는 항목(🔒: 편의성 모음 메뉴, 옵션 메뉴·마법봉 버튼, 보내기 버튼, 메시지의 … 버튼·수정 버튼)은 숨길 수 없습니다. 순서만 바꿀 수 있어요.
   - 목록에는 **지금 테마에서 실제로 보이는 것만** 나와요. (생성 중에만 뜨는 중지 버튼, 스크립트 실행 중에만 뜨는 버튼, 꺼져 있는 버튼 등은 빠짐. 여기서 숨긴 항목은 다시 켤 수 있게 계속 보여요)
   - **메시지 메뉴**: 메시지에 붙은 버튼들을 한 목록으로 정리해요. 기능 버튼(번역·복사 등)이 바로 보이는 테마는 수정·삭제 버튼과 한 줄로 합쳐져서 자유롭게 섞어 배치할 수 있어요. ("…" 메뉴가 있는 테마는 "…" 안의 버튼끼리 순서가 정해져요)
   - 같은 자리를 번갈아 쓰는 버튼은 하나로 묶여요: **보내기 / 요청 중단**(생성 중 스크립트 버튼은 그 바로 왼쪽에 떠요), **메시지 숨기기 / 다시 보이기**.
   - 다른 확장의 요소를 옮기지 않고 보이는 순서만 바꾸기 때문에, 다른 확장 동작에 영향을 주지 않습니다. **기본으로 되돌리기**로 언제든 원래대로.

## 설치

SillyTavern → 확장(Extensions) → **Install extension** → 아래 주소 입력:

```
https://github.com/zxvniqi/ST-QuickActions
```
