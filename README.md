# 편의성 모음 (ST Quick Actions)

SillyTavern 편의 확장입니다. 다른 확장 없이 혼자 동작합니다.

## 설치

SillyTavern → 확장(Extensions) → **Install extension** → 아래 주소를 넣고 설치한 뒤 새로고침합니다.

```
https://github.com/zxvniqi/ST-QuickActions
```

## 사용

입력창 왼쪽 **마법봉 → 편의성 모음**에서 기능마다 켜고 끕니다. 맨 위 **기능 찾기**로 기능을 찾고, 기능 옆 **?** 를 누르면 설명과 쓰는 곳이 나옵니다. 창 맨 위의 **사용**을 끄면 확장 전체가 꺼집니다.

## 기능

- **메시지**: 삭제 버튼 꺼내 두기, 드래그해서 수정·삭제, 답변 넘기기 버튼, 스와이프 목록, 메시지 처음·끝으로 가기, 빈 답변 자동 삭제·재생성, 정규식 렌더링 픽스
- **채팅**: 캐릭터 누르면 채팅 목록부터(캐릭터 삭제도), 채팅 전체 내보내기·불러오기, 채팅 목록 정렬, 채팅 이름 한 번에 바꾸기, 메시지 범위 삭제·숨기기, 메시지 휴지통, 채팅 백업 캐릭터별로 보기·불러오기, 채팅 단어 한꺼번에 바꾸기(미리보기·일부만·단어 단위·범위·되돌리기), 채팅에서 찾기, 시작 화면에 최근 채팅 펼치기, 빈 채팅 덮어쓰기 방지
- **캐릭터**: 목록에서 바로 즐겨찾기·태그, 프로필 사진 고화질, 페르소나 메모·연결 캐릭터·폴더(지금 캐릭터에 연결된 페르소나 보기)
- **입력창·QR**: QR바 정리, QR 입력창 도구, QR 답변도 스와이프로 다시 만들기, 입력창 안내 문구 숨기기
- **바로가기**: 최근 메시지 삭제, 맨 위·아래로, 한 메시지 위·아래로, 번호로 이동, 메시지 범위 숨기기, {{char}}·{{user}} 이름 바꾸기, 마법봉·옵션 메뉴·입력창 버튼·확장 설정 추가
- **프롬프트**: 프롬프트 폴더·관리, 빠른 전환(채팅에 연결하면 그 채팅에서 자동 전환), 프롬프트 항목 메뉴(복사·맨 위로·맨 아래로·삭제)
- **메뉴 정리**: 메뉴 숨기기·순서 바꾸기(입력창 버튼은 왼쪽·오른쪽 사이로도), 확장 메뉴·옵션 메뉴를 아이콘으로, 확장 설정 바로가기(옵션 메뉴·마법봉·메시지 메뉴에서 창으로 열기, 아이콘·처음 탭 고르기), 정규식 폴더
- **화면 · 기타**: ST 한국어 번역 채우기·고치기, ST 설정 설명 글씨 숨기기, 오류 알림 자세히 보기(그 알림 오류만, 이전 것은 접기), 연결 프로필 버텍스(서비스 계정) 오류 픽스, 월드인포 목록 창(찾기·즐겨찾기·정렬·연결 캐릭터), 프롬프트·월드인포·캐릭터 설명 번역해서 보기(여러 곳 동시에, 크게 보기도 번역문)
